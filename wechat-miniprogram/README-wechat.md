# 微信小程序部署全流程

> 结论先说：小程序**必须**在你自己的电脑上用「微信开发者工具」编译上传，Web 端做不了这件事。
> 但上传之后，审核通过别人在手机上打开就完全不需要电脑。
> 数据接口已经指向线上，导入工程后**改一行 AppID 就能编译看到真实行情**。

---

## 第 0 步：现在的数据接口

小程序默认已经连线上数据，位置在 `app.js` 第 5 行：

```js
const ONLINE_API_BASE = 'https://a88818a225005d7a1.app.workbuddy.host/api/dashboard?sharecode=GNZYA6LUMZ';
```

- 链接里的 `?sharecode=...` 是访问凭据，**不能删**，删了会返回 403。
- 用户在「数据」页可以自己改接口地址；改过之后以本机保存的为准，想恢复线上地址可在弹窗里重新粘贴上面这串。

---

## 第 1 步：注册小程序，拿到 AppID（约 10 分钟）

1. 打开 <https://mp.weixin.qq.com> → 立即注册 → 选「小程序」
2. 一个邮箱只能注册一个，未注册过公众号/小程序的邮箱
3. 主体类型选 **个人**（个人主体可以做工具类小程序）
4. 注册完登录后台，在「开发 → 开发管理 → 开发设置」里找到 **AppID**

> 沙箱里没法帮你注册，这一步必须你本人用微信扫码完成。

---

## 第 2 步：配置服务器域名（关键，不做会请求失败）

后台 →「开发 → 开发管理 → 开发设置 → 服务器域名」→ 修改：

| 类型 | 填写内容 |
|---|---|
| request 合法域名 | `https://a88818a225005d7a1.app.workbuddy.host` |

填域名即可，**不要带路径、不要带参数、不要带 sharecode**。

验证方式：后台会要求放一个校验文件。把微信给的 `XXXXXXXX.txt` 放到本项目的 `static/` 目录，
它就能通过 `https://你的域名/XXXXXXXX.txt` 访问（服务端已内置这个路由）。
如果校验文件在线上托管那边放不了，说明这个域名不是你在管理的，**第 6 步换成自己的域名更稳妥**。

---

## 第 3 步：安装开发者工具并导入

1. 下载安装：[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（Windows / macOS 都有）
2. 打开 → 扫码登录 → **导入项目**
3. 目录选 `macro-monitor/wechat-miniprogram`
4. AppID 填第 1 步拿到的，项目名随意
5. 点击「导入」

---

## 第 4 步：本地设置（不勾会报域名错误）

工具右上角 **详情 → 本地设置**，勾选：

- ☑ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书

勾了之后，即使第 2 步还没审核通过，也能先在模拟器里看到数据。
另外建议把「将 JS 编译成 ES5」关掉（代码用了 `Promise`、`Object.values`，基础库足够新，无需降级）。

---

## 第 5 步：编译、真机预览

1. 点工具栏 **编译**，模拟器里应出现四张指标卡：国际金价、国内金价、美元指数、美债 10 年
2. 顶部「已更新」，数据时间与当前接近，说明接口通了
3. 点 **预览** → 生成二维码 → 用你的微信扫码，在真机上验证一遍
4. 真机上依次点：总览 → 趋势（图要不要能拖动看数值）→ 提醒（开关+阈值能否保存）→ 数据

**如果模拟器显示「连接失败」**，按顺序排查：本地设置没勾 → 域名没配 → `app.js` 地址多了/少了字符。

---

## 第 6 步：上传并提审

1. 工具栏 **上传** → 版本号填 `1.0.0`，备注「行情监测工具首版」
2. 回到 <https://mp.weixin.qq.com> →「管理 → 版本管理」→ 找到刚上传的开发版本 → **提交审核**
3. 审核前先在「设置 → 基本设置」补齐：
   - 小程序名称、头像、简介
   - **服务类目**：建议选「工具 → 效率」，不要选金融、证券、投资理财类目
4. 页面里已有免责声明（不构成投资建议），**不要**出现「抄底」「稳赚」「收益」这类词，否则金融类内容容易被驳回
5. 审核通过后点 **发布**，任何人搜到或扫码都能用

---

## 关于「固定域名」

你现在用的 `a88818a225005d7a1.app.workbuddy.host` 是沙箱托管地址，**适合现在测试，不适合做正式上线域名**：它带 sharecode 访问凭据，也无法做微信后台的域名所有权校验。

正式版建议这样（也是「固定域名」的正解）：

| 方案 | 成本 | 域名 | 数据实时性 |
|---|---|---|---|
| **A. 自己的服务器 + 域名** | 服务器约 60–100 元/月，域名 30–60 元/年 | `api.你的域名.com` | 实时，每 30 分钟刷新 |
| **B. 静态托管（GitHub Pages / Cloudflare Pages）** | 免费 | `用户名.github.io/仓库` 或绑自己域名 | 快照，定时任务每天更新 |

部署命令都在项目里：

```bash
# 方案 A：在服务器上
pip install -r requirements.txt
PORT=8000 python3 app.py          # 用 systemd / supervisor 常驻
# 前面挂 Nginx + HTTPS 证书，小程序域名填 https://api.你的域名.com

# 方案 B：生成静态站再上传
python3 scripts/export_static.py   # 产出 static-site/
```

方案 A 配好后，把 `app.js` 里的 `ONLINE_API_BASE` 换成 `https://api.你的域名.com/api/dashboard`，
然后重新上传一版即可。方案 B 的接口地址是 `https://你的站点/mp`（读 gold.json 与 macro.json，小程序已同时支持两种接口）。

> 域名需要 ICP 备案（中国大陆服务器）。Cloudflare Pages / GitHub Pages 走境外，可免备案，但国内访问速度一般。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `request 合法域名校验出错` | 域名没配或没勾「不校验合法域名」 | 做第 2、4 步 |
| 403 / 页面提示链接不完整 | 接口地址里的 `?sharecode=` 被删了 | 补回完整链接 |
| 数据是昨天的 | 服务端每 30 分钟刷新，美债按美国交易日更新 | 正常现象，卡片上有行情时间 |
| 真机白屏、模拟器正常 | 真机没勾调试基础库或网络差 | 真机开启「调试」模式看 console |
| 审核被拒：涉及金融 | 类目或文案触碰金融投资 | 改类目为工具类，删掉暗示收益的措辞 |

## 一次真实流程要多久

| 阶段 | 耗时 |
|---|---|
| 注册 + 拿 AppID | 10 分钟（个人主体可能需 1 天审核） |
| 配域名 + 导入 + 编译 | 10 分钟 |
| 上传 + 提交审核 | 5 分钟 |
| 官方审核 | 通常 1–3 个工作日 |
